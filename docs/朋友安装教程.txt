赛博金毛 0.3.0 安装教程（先看这个文件）

适用电脑：Windows 10 / Windows 11，64 位。
不用安装 Steam、.NET 或开发工具，也不用账号、API Key。

一、先点哪个，后点哪个

1. 先打开“金毛安装包”文件夹，阅读本教程。

2. 双击：CyberGolden-Setup-0.3.0-x64.exe
   这就是安装程序，不需要解压，也不要找其他 EXE。

3. 如果先出现“欢迎使用安装向导”页面，点“下一步”。
   如果直接出现“许可协议”页面，就从下一步开始。

4. 在“许可协议”页面：
   先选择“我同意此协议”，再点“下一步”。

5. 在“选择目标位置”页面：
   保留默认安装位置，直接点“下一步”。
   一般不用改安装目录。

6. 在“选择附加任务”页面：
   建议勾选“创建桌面快捷方式”，再点“下一步”。
   勾选后，以后可以从桌面直接打开金毛。

7. 在“准备安装”页面：
   点“安装”，等待进度条完成。

8. 在安装完成页面：
   保留“启动赛博金毛”的勾选，再点“完成”。
   狗狗就会出现在桌面上。
   如果没有勾选启动，可以双击桌面的“赛博金毛”，
   或从开始菜单找到“赛博金毛”打开。

二、第一次打开后怎么用

狗狗默认正面静坐。右键狗狗可以打开功能菜单。

· 左键按住狗狗拖动：调整位置。
· 点击头部：摸头。
· 点击身体：查看状态。
· 右键 → 喂食 / 喝水 / 握手 / 玩网球 / 玩小玩偶。
· 右键 → 设置：选择并保存坐姿、站姿、趴姿，调整大小和声音。
· 想完全不走动：在设置中取消“允许自主散步”。
· Ctrl + Alt + D：隐藏 / 恢复狗狗。
· 找不到狗狗：查看右下角系统托盘，也可以在那里显示或退出。

三、用空文件夹喂食

1. 自己新建一个普通本地空文件夹。
2. 把这个文件夹拖到狗狗身上。
3. 狗狗会吃饭，饱食度增加；文件夹保持原样，可反复使用。

只有把文件夹拖到狗狗身上才会喂食。
仅仅新建文件夹不会自动投喂。
非空文件夹、文件、网络目录不接受。
喂食没有间隔限制，饱食度满了也可以继续喂。

四、保存和卸载

名字、位置、大小、姿势和养成状态会自动保存。
重新打开会恢复设置；隐藏、暂停、睡觉也会保留。

卸载：打开 Windows“设置” → “应用” → 找到“赛博金毛” → “卸载”。
也可以从开始菜单点击“卸载赛博金毛”。
卸载时默认保留存档；只有自己主动选择清除才会删除。

说明：安装包已在开发电脑完成实际安装、启动与卸载验证。
干净虚拟机和真实多显示器环境仍未完成全部验证。
