## 赛博金毛 Android 0.1.0 测试版

安卓手机直接下载 **CyberGolden-Android-0.1.0.apk** 安装，然后开启赛博金毛的悬浮窗权限。完整步骤见附件 `Android-Install-ZH.md` 或 [安卓安装教程](https://github.com/Jake-Daxon/cyber-golden/blob/main/docs/安卓安装教程.md)。

- 支持 Android 8.0 及以上，纯 Java 通用 APK，不区分骁龙/天玑等处理器。
- 默认正面静坐，支持选择并保存站姿、趴姿；保留喂食、摸头、握手、睡眠、声音、玩具与饥饿提醒。
- 喂食无间隔，满饱食度仍可喂；+15、上限100，普通主动互动扣4、运行每小时扣2，离线补算封顶。
- 通知栏隐藏/恢复/关闭；锁屏停止动画和声音，私有本地存档，无网络权限、账号、广告或首次启动下载。
- 同一只金毛、同一套连续动画和声音；Android 使用原生显示和状态适配，Windows 版仍复用 VPet Core。

这是首次安卓测试版，未逐台验证真实品牌手机的后台省电和悬浮权限。手机投喂为食盆按钮；无 Windows 文件夹拖放、托盘或键盘快捷键；透明区域触摸表现受 Android 窗口规则限制。详细范围见 [安卓验证报告](https://github.com/Jake-Daxon/cyber-golden/blob/main/docs/安卓验证报告.md)。

**iPhone / iPad 无法安装此 APK。** Windows 用户继续下载原来的 [Windows 0.3.0](https://github.com/Jake-Daxon/cyber-golden/releases/tag/v0.3.0)，已有 Windows 下载保持可用。

`Android-SHA256SUMS.txt` 提供安装包 SHA-256。原始参考照片、用户存档、签名密钥和测试入口均不包含在 APK 中。许可证内置于 APK 的 assets/licenses，源码保留于同一仓库的 android 目录。
