# 赛博金毛 0.4.1 本地体验版

先从托盘或右键退出旧金毛，再运行 dist/CyberGolden-0.4.1-preview-win-x64/CyberGolden.exe；设置窗口标题会显示“0.4.1体验版”。也可安装本地体验安装包。此版本尚未同步GitHub，本轮按作者要求未做效果测试。

## 此轮修正

- 拎起不再是菜单或随机动作，只有实际拖动时出现。修正VPet把单帧PNG加载为静态图而原入口只支持连续动画的问题；现在拖动直接使用同一静态图加载路径，右前爪自然搭在下腹部。
- 每轮饥饿最多播放两声；不会持续叫，也不会因重启反复叫。仍可关闭，服从静音、安静模式、隐藏、暂停和睡眠。
- 饥饿去中央的前两次拖动松手后继续，第三次取消本次移动。
- 坐下观察和趴下休息播放一遍，只延长尾帧停留；开心蹦跳仍保留重复延长。

## 新的网球玩法

1. 右键选择“玩网球”，球会出现并落到工作区底部，小狗等待。
2. 用鼠标按住球，移动球的位置。滑动后松手可以抛出；停住后松手则自由下落。
3. 球会受重力下落，在工作区边缘与底部反弹，并因阻尼和摩擦停稳。
4. 球抛出并停稳后，小狗跑到球旁、捡起并叫一声。
5. 小狗带球回点击玩网球时的原位置，再叫一声并放下。球可以再次拾取抛出，进行下一轮。
6. 重新抓球会让小狗等待新的落点；菜单、其他明确命令、隐藏、拖动小狗等仍可结束当前陪玩。球不会进入任务栏或自动跨显示器。

安卓使用相同流程，以手指按住球、滑动松手抛出。投喂、摸头/前爪握手/身体随机动作、点击不打断、拖动扣2、默认趴下、5～1000秒漫游CD、安静模式、音量增益、托盘/快捷键和设置页定制文字保持上轮修改。

普通主动互动扣4；喂食+15封顶100，不设喂食间隔，满饱食度仍可喂。养成数据、位置、设置与饥饿记录保存在当前用户应用数据目录。许可证和声音来源见NOTICE。实际体验由作者确认。
