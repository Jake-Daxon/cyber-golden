# 赛博金毛 0.3.0

这是可运行的 Windows x64 本地桌宠。默认使用握手动画的正面形象、双爪落地静坐，普通待机不持续循环。设置中可选择并保存静坐、站立或趴下；互动结束回所选姿势。自主漫游保留，默认 CD 180～240 秒，可关闭“允许自主散步”。指定睡觉继续保持睡眠。当前保留 20 组、120 个动作关键帧和 3 张静止姿势。

安装：运行 CyberGolden-Setup-0.3.0-x64.exe，当前用户安装，无需管理员、Steam、账号或单独安装 .NET。可以选择桌面快捷方式。便携版解压整个 ZIP 后运行 CyberGolden.exe，不要只复制 EXE。

左键拖动狗；单击头部摸头；单击身体查看五项状态；右键打开喂食、喝水、握手、网球、小玩偶、睡觉/叫醒、取消动作、设置、隐藏及退出。设置中可以改名、调整 96～240 DIP 大小、声音与 0～100% 音量、置顶、自动行走、安静模式和等待时间。文本设置只在你明确打开并点击设置窗口时接收输入。

Ctrl+Alt+D 全局隐藏/恢复；系统托盘也提供相同入口。快捷键冲突时设置窗口会显示状态，可以换为 Ctrl+Shift+F8 等组合。隐藏会清理玩具和声音并取消临时动作。睡觉、隐藏、暂停会在下次启动保持；喂食、追逐等临时动作不会重播。

默认约 160×160 DIP；透明留白不挡鼠标。普通待机静止，漫游按独立 CD 开启，三分钟无键鼠输入后进入安静陪伴。关闭静止设置可恢复低频随机小动作。移动限定当前显示器工作区；只读取系统最后输入时间戳，没有摄像头、远程聊天或首次启动下载。

空文件夹投喂：把一个普通本地空文件夹拖到狗身上，或用右键喂食。两者无时间冷却，饱食度满 100 仍可继续喂，新的喂食立即替换旧动画，不排队。每次新的投喂 +15、上限 100；同一个拖放事件只结算一次。文件夹只读检查，不删除、移动、重命名、写入或监听创建，可重复使用。

饱食度每次普通主动互动扣 4（拖动也算）；喂食只补 15，界面/隐藏/睡觉控制操作不扣。运行每小时扣 2，离线最多补算 4 小时。低于 15 出现持续“我饿了”气泡，达到 30 立即消失。每轮首次正常活动时到当前工作区中央一次，精力足够小跑、不足慢走，然后回所选姿势；出发记录立即保存，中断或重启不重复移动。饥饿叫声至少间隔 30 分钟，可单独关闭，且服从全局静音和音量。隐藏时气泡隐藏；暂停、睡眠和 AFK 保留文字，但不移动或叫，不补播过期任务。详细规则见源码 docs/最新规则.md。

声音默认 20%，睡眠呼吸默认关闭；随机待机和安静陪伴不会叫。声音为随包提供的狗叫授权录音衍生及原创程序 Foley，不是照片幼犬的实际声线。来源及许可见 NOTICE.txt。

数据：%LOCALAPPDATA%\CyberGolden\state.json；备份 state.json.bak；缓存 cache；故障日志 diagnostic.log。损坏主存档会尝试备份，均损坏时回到默认设置。不要把自己的数据目录放入分享包。

卸载：Windows 的“安装的应用”或开始菜单卸载入口。默认保留存档；只有在卸载界面主动选择清除时才删除。开机启动默认关闭，只有你在设置中主动开启时才写入当前用户登录启动项。

分享：将 dist 中安装 EXE 或便携 ZIP 发给朋友。程序无运行时联网代码，所有动画、声音、配置和 .NET 运行环境均在包中。未申请代码签名；暂未公开上传。
