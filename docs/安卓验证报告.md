# Android 0.1.0 验证报告

2026-10-10。Windows 0.3.0 及其已有安装包保留不变。

## 实现

- 原生 Java Activity + TYPE_APPLICATION_OVERLAY + specialUse 前台服务；中文 App、权限引导和通知控制。
- 复用现有 20 动作 / 120 连续帧、3 静止姿势和 5 声音。手机显示层与状态机改写适配 Android，不运行 Windows WPF / VPet DLL。
- 默认静止正面坐姿、姿势保存、主动命令、中断、摸头、拖动、喂食、饮水、握手、小动作、睡眠、玩具叼回、漫游、饥饿、隐藏、暂停、静音及私有原子存档。
- 沿用最终喂食规则：无间隔、满饱食度仍可喂、+15 / 上限100、普通主动互动扣4、运行2/小时、离线4小时封顶。
- 饥饿阈值15/30，每轮中央移动只记录一次，提醒声至少30分钟；关键状态在渲染第一步移动前保存。
- App 无 INTERNET 权限、无账号、无广告、无屏幕捕获/辅助功能权限，不监控其他 App。原始参考照片、用户数据、私有签名密钥和测试入口不打包。

## 已通过

- JDK 21、Google Android SDK 36 / Build Tools 36.0.0 实际编译。
- 52 项纯 Java 行为断言：静止待机、连续/满饱食度投喂、重复请求去重、消耗、离线补算、阈值滞回、中央一次、精力步态、中断、屏蔽状态、声音限频、恢复及玩具流程。
- APK v2 / v3 发行签名验证、zipalign、manifest 包名/API/权限检查。
- 实体动画、姿势、WAV 与适用许可证接入 APK；不依赖源码路径或首次下载。
