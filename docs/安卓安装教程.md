# 赛博金毛安卓安装教程

适用于 Android 8.0 及以上安卓手机。iPhone / iPad 不能安装 APK。

## 先点哪个，后点哪个

1. 在**安卓手机**浏览器打开 [安卓下载页](https://github.com/Jake-Daxon/cyber-golden/releases/tag/android-v0.1.0)。
2. 在 Assets 中点击 `CyberGolden-Android-0.1.0.apk`，等待下载完成。
3. 点击已下载的 APK。若系统询问安装来源，允许当前浏览器或文件管理器安装此应用，再回到安装页面。
4. 点**安装**，安装完成点**打开**。
5. 在赛博金毛中点击**开启手机桌宠**。
6. 手机会进入系统权限页面，找到赛博金毛，允许**显示在其他应用上层**。不同品牌也可能叫**悬浮窗**。
7. 返回赛博金毛。首次开启可允许通知，方便从通知栏隐藏、恢复或关闭桌宠。
8. 返回手机桌面，狗狗会出现在屏幕上。无需连接电脑、Steam、账号或开发工具。

## 怎么玩

- 轻点狗狗：摸摸头。拖动：改变位置。长按：显示喂食、喝水、握手、睡觉、网球和隐藏菜单。
- App 内提供完整互动按钮、玩偶、更多小动作、名字、姿势、大小、音量、全局静音及饥饿声音开关。
- 普通待机保持静止，可选坐姿、站姿、趴姿；互动结束返回选定姿势。默认沿用握手动作的正面形象，双爪落地。
- 开启漫游后，隔几分钟偶尔移动一小段；关闭它可以一直静坐。约十分钟没有与狗狗互动后进入安静陪伴，不监控其他 App 的操作。
- 手机使用**食盆按钮**喂食，不使用电脑上的空文件夹拖放。每次成功喂食 +15、上限 100；没有喂食间隔限制，满饱食度也能继续喂。普通主动互动扣 4，运行每小时扣 2，离线最多补算 4 小时，离线下降保底 5。
- 低于 15 显示“我饿了”，达到 30 解除；每轮饥饿最多向可用屏幕中央走一次，叫声至少间隔 30 分钟。隐藏、暂停、指定睡眠或安静陪伴期间不执行饥饿移动/叫声。
- 通知栏点**隐藏 / 显示**可以恢复狗狗，点**关闭桌宠**完全停止悬浮服务。存档保留。
- 锁屏时暂停可见动画、玩具和声音；解锁后重新判断当前状态，不补播过期互动。

## 如果狗狗不见了

1. 先打开 App，检查是否隐藏、是否允许悬浮窗；再点**开启手机桌宠**。
2. 部分手机的省电管理会结束后台 App。可在系统的赛博金毛应用设置里允许后台运行，名称依品牌不同。程序不会自动修改这些设置。
3. 某些支付、权限或安全页面会由系统禁止悬浮显示，这是手机系统行为。
4. 关闭权限或系统结束服务后，请手动打开 App 再开启桌宠；首次版本不自动开机启动。

## 安卓与电脑版的区别

安卓使用自己的窗口和状态适配，没有 Windows 托盘、Ctrl+Alt+D、文件夹拖放或多显示器功能。安卓系统按窗口区域处理触摸，狗狗方形窗口内部的透明部分不能保证像 Windows 一样逐像素穿透；可拖到边缘或从通知栏隐藏。饥饿气泡与玩具另用不可触摸的半透明窗口，遵守 Android 12+ 的遮挡透明度规则。

本地存档位于应用私有数据目录；覆盖安装同签名 APK 可保留设置，卸载 App 通常会清除数据。安卓和 Windows 存档不会自动同步。

本版为首次安卓测试版。真实品牌手机的权限、省电和声音体验仍需实际使用确认，已验证项目见 [安卓验证报告](安卓验证报告.md)。
