# 0.3.0 最新规则（取代此前冲突要求）

普通待机始终显示保存的静态姿势，不持续循环。默认使用握手动作的正面形象、双爪落地静坐，可选站立或趴下。保留自主漫游，默认 CD 180～240 秒，每次用真实步态慢走/低频小跑；可关闭“允许自主散步”或启用安静模式。静止设置控制随机小动作，保留全部主动动作；互动结束回所选姿势。

投喂：右键“喂食”，或者把一个普通本地空文件夹拖到狗身上。两入口共用 Feed 事务。无时间间隔限制、无饱腹拒绝；满 100 仍可继续喂，动画可立即替换当前喂食。每次新的投喂补 15，上限 100，只对同一个事件 ID 防重复结算；不叠加动画任务。声音另遵守全局音量/静音与限频，取消喂食冷却不取消声音限频。

文件夹仅作可重复使用的食盆：只检查是否普通、本地、空目录；不监听文件夹创建、不删除、不移动、不重命名、不写入、不建立快捷方式。非空目录、文件、网络路径、系统目录及重解析点不接受。没有在存档或日志记录投喂文件夹路径。

饱食度：普通主动动作和拖动每次扣 4，喂食只增加 15；打开菜单/设置/状态、隐藏/恢复、睡觉/叫醒等控制操作不扣。正常运行另每小时扣 2，隐藏/暂停/睡眠也按时间结算。离线每小时补算 2、最多 4 小时，不永久死亡。

饥饿：低于 15 进入，恢复到 30 或以上解除。气泡“我饿了”持续显示，跟随狗、避边界、全窗鼠标穿透；隐藏同步隐藏，暂停/睡眠/AFK的可见状态保留文字，饱食度解除立即消失。

本轮第一次符合正常活动条件时，用小跑（精力≥30）或慢走去当前显示器工作区中央，随后轻叫并回所选姿势。首次出发前就把“本轮已尝试移动”原子保存，中途被拖动/菜单/命令/隐藏打断也不重新出发。重启不重复本轮中央移动。喂饱解除后再进入才算新一轮。

后续饥饿叫声至少间隔 30 分钟，可单独关闭，也服从全局静音、音量和声音限频。隐藏、暂停、指定睡眠、AFK期间不移动、不叫、不排队；过期叫声顺延，不在恢复时补播。恢复正常后依据当前食量和本轮记录重新判断。

记录仅新增状态/事务标记和提醒时间戳，不增加新的养成数值。动画、声音、饱食度和行为仍复用已有 VPet Core 与本项目资源。
