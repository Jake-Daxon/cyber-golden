Modifications, 2026-10-10: independent offline WPF host, behavior engine, local
user persistence, silhouette hit region, toys and local audio; Core retargeted to
.NET 10; deterministic frame sorting, stale playback guards and frame events.
No original VPet character animations, Steamworks, workshop, account/API or
network initialization are part of the CyberGolden runtime.

Derivatives click.wav / happy.wav: cropped, mono, resampled/pitched up,
low-pass filtered, normalized and faded; happy contains two softened barks.
These two derivatives are distributed under the same CC BY-SA 3.0 license.
This recording is NOT the photographed puppy and its age/breed is unknown.
eat.wav / drink.wav / breath.wav: original deterministic procedural foley,
not a recording of the puppy; project contributors dedicate these three files
to CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

Artwork: generated with built-in imagegen using user-supplied puppy photos and
PNG identity references. Side/back anatomy, tail and all motions are inferred.
Original user photos/references are deliberately excluded from installer/ZIP.
No third-party font files are bundled. UI uses installed Windows system fonts.
Toy drawings and app icon are project artwork.
